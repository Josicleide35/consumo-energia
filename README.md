# ⚡ Consumo de Energia

## 📌 Objetivo
Programa em Python que calcula o consumo mensal de energia de um aparelho.

## 🐍 Linguagem
Python

## 🧮 Fórmula
consumoMensal = (potencia × horasDia × 30) / 1000

## 💰 Custo
O programa calcula também o custo estimado usando R$ 0,75 por kWh.

## ▶️ Como executar
No terminal, execute:

python app.py
